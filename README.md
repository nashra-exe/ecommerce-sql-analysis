============E-Commerce SQL Analysis=============



\---- Project Overview ---------



This project analyzes an e-commerce database using MySQL to understand customer behavior, product performance, sales patterns, and revenue trends.



The database contains three tables:



\* `customers` — customer information

\* `products` — product details, categories, prices, and inventory

\* `orders` — customer orders, quantities, dates, and order status



\--------- Objectives ------------



The main objectives of this project are to:



\* Analyze customer spending and ordering behavior

\* Identify high-performing products and categories

\* Analyze revenue and sales trends

\* Examine order statuses and purchasing patterns

\* Practice SQL techniques used in real-world data analysis



\------ SQL Techniques Used ------------



\* Database and table creation

\* Data validation

\* SELECT, WHERE, ORDER BY, LIMIT

\* DISTINCT and filtering

\* INNER JOIN

\* LEFT JOIN

\* Aggregate functions

\* GROUP BY and HAVING

\* Subqueries

\* Common Table Expressions (CTEs)

\* Window functions

\* RANK()

\* ROW\_NUMBER()

\* PARTITION BY

\* CASE statements

\* Date functions

\* Arithmetic calculations

\* NULL and duplicate checks

\---------- Key Analysis Areas ------------



\### Customer Analysis



Analyzed customer spending, order frequency, customer rankings, and customer activity across different cities.



\### Product Analysis



Analyzed product prices, product-level revenue, category performance, and high-performing products.



\### Sales Analysis



Calculated total revenue, revenue by category, units sold, monthly revenue, and order-status distributions.



\### Advanced SQL Analysis



Used subqueries, CTEs, and window functions to perform comparisons, rankings, and above-average performance analysis.



\## Example Business Questions



Some of the questions explored in this project include:



\* Which customers generate the highest revenue?

\* Which products generate the most revenue?

\* Which categories generate the most revenue?

\* Which customers spend above the average customer spending?

\* Which products perform above their category average?

\* Which products generate more than ₹50,000 in revenue?

\* Which product has the highest revenue within each category?

\* How does revenue change across months?

\* How do customers rank within their cities?

\* Which products have not received any orders?
